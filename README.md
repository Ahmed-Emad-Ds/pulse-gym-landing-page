# Pulse Gym Landing Page

A modern, professional, and fully responsive gym landing page built using **HTML5** and **CSS3** only (no frameworks or JavaScript used). This project was developed as part of a structured web development assignment, following a professional Git and GitHub workflow (feature branches, clean commits, and merges).

## 🚀 Project Overview
The **Pulse Gym Landing Page** is designed to provide fitness enthusiasts with an immersive introduction to a high-end gym. It highlights top-tier training programs, state-of-the-art facilities, flexible membership plans, expert certified coaches, and customer testimonials.

### ✨ Key Features
* **Semantic HTML5 Structure:** Built using proper semantic tags (`header`, `nav`, `main`, `section`, `footer`).
* **Modern CSS3 Layouts:** Styled entirely with CSS using **Flexbox** and **CSS Grid** for precise alignment and responsiveness.
* **Fully Responsive:** Optimized for all screen sizes (Desktop, Tablet, and Mobile).
* **Pure CSS/HTML:** Built without any external CSS frameworks (like Bootstrap or Tailwind) or JavaScript dependencies.

---

## 📑 Included Sections
1. **Navigation Bar:** Gym logo, smooth navigation links, and a Call-to-Action (CTA) button.
2. **Hero Section:** Main headline, description, promotional buttons, and featured imagery.
3. **Gym Statistics:** Key metrics including ratings, floor size, equipment count, and operating hours.
4. **Training Programs:** Detailed cards for Strength & Powerlifting, HIIT, HYROX, and Mobility.
5. **Gym Facilities & Features:** Highlights of equipment, medical body-scanning, recovery zones, and security.
6. **Membership Plans:** Three pricing tiers with clear features and CTA buttons.
7. **Certified Coaches:** Profiles featuring coach images, names, specialties, and bios.
8. **Customer Testimonials:** Member reviews and ratings.
9. **Call-to-Action Section:** Promotional section encouraging users to claim a 3-day free pass with a registration form.
10. **Footer:** Contact details, operating hours, location, and useful links.
